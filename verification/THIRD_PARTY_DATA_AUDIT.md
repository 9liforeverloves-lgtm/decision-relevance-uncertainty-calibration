# Third-party data audit

| Dataset | Source | Terms status | Redistributed? | Justification and reproduction route |
|---|---|---|---|---|
| Matbench tasks used by the study | Matbench / Materials Project and upstream dataset providers | The local audit found no uniform task-level redistribution license. Provider-specific terms still need author review. | No raw source tables, per-candidate records, candidate-state files, or complete trajectories are included in the clean package. | Retrieve source data from the original provider routes only after checking their terms; see the official Matbench documentation and cited dataset paper. |

The Matbench software repository license is not treated as a license for every underlying dataset record. The Matbench paper describes a benchmark built from ten DFT-derived and experimental sources ([Dunn et al., 2020](https://www.nature.com/articles/s41524-020-00406-3)); provider access routes are listed in the [official Matbench documentation](https://docs.materialsproject.org/services/ml-and-ai-applications/matbench). This is an unresolved permission status, not a conclusion that redistribution is prohibited. Public release of derived record-level data also remains unapproved.
