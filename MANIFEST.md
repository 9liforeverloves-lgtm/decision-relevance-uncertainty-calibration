# Release manifest

`SHA256SUMS.txt` lists the SHA-256 hash and repository-relative path for every staged file except the hash list itself. `manifests/README.md` describes its scope.

The curated release includes manuscript sources/PDFs, selected scripts and protocols, aggregate results, figures, and audit records. It excludes raw third-party Matbench tables, full third-party record-level copies, candidate-state Parquet files, complete run trajectories, credentials, temporary artifacts, and machine-specific local paths. The exclusion of source and derived record-level data is the chosen redistribution scope because those permissions have not been established; only authorized materials are staged.
