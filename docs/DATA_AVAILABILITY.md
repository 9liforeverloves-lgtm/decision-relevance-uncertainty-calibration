# Data availability

Analysis code, configuration files, aggregate result tables, verification manifests, and reproducibility documentation are available at https://github.com/9liforeverloves-lgtm/decision-relevance-uncertainty-calibration. The source Matbench datasets are available from their original providers and are not redistributed by this repository where redistribution rights are not established. The repository documents the data-acquisition and analysis workflow used for the reported results. It does not redistribute raw Matbench tables, third-party source datasets, complete record-level copies, candidate-state Parquet files, or full run trajectories.

Obtain the benchmark inputs through the [official Matbench documentation](https://docs.materialsproject.org/services/ml-and-ai-applications/matbench) and the original providers. Provider-specific terms apply. This repository does not relicense those datasets. The aggregate tables are the outputs needed to inspect the reported summary effects; they do not enable reconstruction of all candidate-level or seed-level analyses.

No DOI is assigned. The repository URL and included contents were verified for this release.
