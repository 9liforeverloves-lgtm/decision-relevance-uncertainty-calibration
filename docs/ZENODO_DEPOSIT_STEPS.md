# Optional Zenodo deposit

Zenodo is optional. No Zenodo DOI has been created or is claimed.

After the GitHub repository and a reviewed GitHub release exist:

1. Sign in to Zenodo and connect the GitHub account that owns the repository.
2. Enable archiving for `decision-relevance-uncertainty-calibration`.
3. Create the reviewed GitHub release `v1.0.0-rc1` and allow Zenodo to archive it.
4. Verify the archived files and metadata, then record the DOI returned by Zenodo.
5. Only after verification, add the DOI to `CITATION.cff` and update the manuscript, ScholarOne metadata, and availability options.

Do not add a DOI before Zenodo has issued and verified it. The current task does not create a Zenodo deposit.
